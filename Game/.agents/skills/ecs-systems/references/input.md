# Keyboard and gamepad input

Bind named actions in `input.json` at the project root (`{ "actions": { "moveX": [{ "negative": "ArrowLeft", "positive": "ArrowRight" }], "jump": [{ "key": "Space" }, { "button": 0 }] } }`; keys are `KeyboardEvent.code` names: `KeyA`, `Digit1`, `ArrowUp`, `Space`) and read the `ActionState` entities (compare `name` with `stringId('moveX')` resolved before the loop, `value` -1..1, `pressed`, `justPressed`, `justReleased`) in a sim system; the same input works in the editor's Play view, `gameengine run` and gamepads. A name the engine does not know logs `input.json: unknown key` and never fires. Raw keys come as `KeyEvent { code, down, mods }`, where `code` is `Keys.<name>` from `@gameengine/runtime` (`keyName(code)` goes back), never a browser `keyCode`. The `ActionState` entities outlive scene switches (like resources), so a system that cached nothing keeps reading them in the next scene. Tests press keys by name: `input.key('ArrowRight', true)`. Example: `samples/tile-maze` (`KeysToTarget`).
