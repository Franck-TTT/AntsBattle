# Ants Battle

A Tactile Game Engine game, made from the Tactile Game Engine game template. The game project is
`Game/`, the Build Server pipelines are in `Build/`. `node template/setup.mjs . --set NAME=value` adds a
value not set yet, and `node template/configure.mjs --check` lists what is still missing (`template/README.md`).

This project was created from the template included with Tactile Create Code. This copy may be older than the current online template.
